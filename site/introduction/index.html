Know what Git will do, before it does it.

GitViz is a Git client for Mac. It shows your history as a clear graph and previews merges, rebases and resets before they touch your repository. Free, local, no account.

See it. Preview it. Undo it.

The graph shows what happened. Previews show what will happen. Recovery points make mistakes survivable.

Stage down to a single line

Click a hunk header or individual +/− lines to stage exactly what belongs in this commit. Unified and side-by-side diffs share the same selection.

Learn the command behind every click

Turn on Show Git commands in Settings and GitViz shows the actual Git command it ran, with a short explanation and a copy button. Credentials in URLs are hidden. The interface also switches between English and 中文 at any time.

Preview before you act

Merge, rebase, cherry-pick and reset are rehearsed in an isolated copy first. See the resulting graph and file changes; GitViz warns you if the repository changed in the meantime.

Recovery points

Before risky operations GitViz saves a recovery point, kept for 30 days or up to 2 GiB by default, so you can get back to where you were.

Drag to merge or rebase

Drag one branch onto another, choose merge or rebase, and review the preview before anything changes.

Three-way conflict resolution

See the common ancestor and both sides, pick a side block by block, or edit the whole file. Drafts survive switching between files.

Blame that follows the line

Trace a line back through renames and earlier versions, and move between steps with back and forward navigation.

Edit history interactively

Reorder, reword, squash, fixup or drop up to 500 commits on a linear range, with an isolated preview and a way to abort or restore.

A graph that stays readable

Every branch keeps its own color across the graph, labels and sidebar. Hover a branch to light up just that line. Tens of thousands of commits load page by page.

Insights into your history

A commit heatmap, top contributors and the files that change most, over the last 30, 90 or 365 days, or all time.

  • Light and dark themes, in English or 中文.
  • Syntax-highlighted diffs for Kotlin, Java, JavaScript, TypeScript, JSON and Python.
  • Keyboard first: j / k to move, ⌘ ⇧ P for the command palette.
  • Works with your existing SSH keys and keychain.

Your repositories stay yours.

GitViz reads your local repositories on your Mac and uses your system Git for every change.

  • No accountOpen a folder and start.
  • No analyticsGitViz reaches the network only when you fetch, pull, push or clone, using your system Git.
  • Passwords never pass through GitVizWhen a remote asks for credentials, Git and SSH show the standard macOS prompts. GitViz neither sees nor stores them.
